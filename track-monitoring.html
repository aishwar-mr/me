Integrated Track Monitoring System

Smart India Hackathon 2025 · Top 3 of 80 teams · Team of 7 · Sep–Oct 2025 Python, OpenCV, ESP32, IMU, laser sensors

The problem

Indian Railways runs roughly 68,000 km of track. Every kilometre has to be checked for defects — rails drifting out of alignment, broken fasteners, ballast that’s shifted, surface cracks. Miss one and you get a derailment.

The checking is done by specialised Track Recording Cars. India’s current system is imported, costs around ₹180 crore, runs on closed-source software, and can’t be customised or repaired locally. If a zone wants only part of the system, it can’t have it — it’s all or nothing, from one vendor.

There’s a second, quieter problem. When a defect is found, you need to know exactly where it is so a maintenance crew can go fix it. The current system locates defects by GPS, and GPS fails in tunnels, cuttings, and dense urban corridors — precisely the places where track problems tend to be worst.

What we built

A contactless prototype that does the same job with off-the-shelf components — nothing touches the rail, so it can run at speed without wear.

Measuring the track. Laser and ultrasonic sensors read the rail profile and geometry. An IMU picks up vibration and misalignment through vertical and horizontal acceleration. An optical encoder tracks distance travelled. Together these produce the standard track geometry parameters — gauge, alignment, unevenness, elevation — that inspectors already work with.

Seeing the defects. Cameras feed an OpenCV pipeline that flags broken fasteners, ballast infringement, and rail surface damage from 1920×1080 video. When something is detected, the system sends an SMS alert with the location attached.

Knowing where you are. Rather than relying on GPS alone, we fused GPS with IMU data and encoder-derived distance. When the satellite signal drops, the system keeps counting position from the wheel and the motion sensors. This was the piece we were proudest of — it directly addresses why the existing system’s localization is unreliable.

Processing on board. First-pass fault detection happens on the device itself, so there’s no dependency on connectivity in the field. Longer-term trend data syncs to the cloud for predictive maintenance. Outputs export as CSV, XML, and JPEG, so they drop into the workflows railways already run.

The design decisions that mattered

Modular by default. A railway zone can deploy just the geometry module, or just the rail profile module, or the whole thing. The existing system doesn’t allow this, and it’s a large part of why it’s expensive.

Standards first, not last. We mapped every output to RDSO TM/IM/448 and EN 13848 Parts 1–2 — the Indian and European track geometry standards — so the numbers the system produces are directly comparable against the tolerance bands inspectors already use. A measurement nobody can act on isn’t worth taking.

Open stack. Python, OpenCV, SQL. No vendor lock-in, maintainable by Indian engineering teams.

What happened

We built it, mounted it, and tested it on live Central Railway track in Mumbai — not a lab rig. Track geometry extraction and real-time data acquisition both worked in the field.

Our costing put an indigenous version at roughly ₹30 crore against the ₹180 crore imported system, with the savings coming from commodity sensors and an open software stack rather than from cutting capability.

The submission placed us in top 3 of 80 teams.

What I’d do differently

The ₹30 crore figure is a hackathon estimate, not a procurement quote — it needs a real BOM and vendor pricing to stand up.

We also identified but didn’t implement RFID tags on track as a further localization improvement. GPS-plus-IMU drifts over long distances; fixed physical reference points would correct that drift. That’s the obvious next iteration.

And we validated that the system works, not how accurately it works. A serious version needs measured error bounds against a calibrated reference — which is the difference between a prototype and something a railway would actually buy.
